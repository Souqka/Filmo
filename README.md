# Слот-машина фильмов

Одностраничное веб-приложение для случайного выбора фильма или сериала из вашего списка. Барабан в стиле казино Лас-Вегаса, поиск через [TMDB](https://www.themoviedb.org/), работа на GitHub Pages без серверной части.

## Возможности

- Поиск фильмов и сериалов через The Movie Database API с автодополнением (debounce 500 мс)
- Поддержка русского и английского языков
- Список в виде чипов: мини-постер, название, редактирование и удаление
- Сохранение списка в `localStorage` (с запасным вариантом, если хранилище недоступно)
- Вертикальный слот-барабан с замедлением `cubic-bezier(0.25, 0.1, 0.25, 1)`
- Честный случайный выбор (равная вероятность для каждого фильма)
- Звук победы через Web Audio API
- Настройки: скорость вращения, звук, сброс данных
- Тёмная казино-тема, адаптив для телефона / планшета / десктопа
- PWA-манифест: приложение можно установить на телефон
- Навигация с клавиатуры и ARIA-атрибуты

## Быстрый старт

1. Получите бесплатный API-ключ TMDB:
   - зарегистрируйтесь на [themoviedb.org](https://www.themoviedb.org/signup)
   - откройте [настройки API](https://www.themoviedb.org/settings/api)
   - создайте ключ (API Key v3)
2. Вставьте ключ в `config.js`:

```javascript
TMDB_API_KEY: 'ваш_ключ_сюда',
```

3. Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
python3 -m http.server 8080
```

Затем перейдите на `http://localhost:8080`.

> Поиск не заработает, пока в `config.js` стоит заглушка `YOUR_API_KEY_HERE`.

## Публикация на GitHub Pages

1. Залейте репозиторий на GitHub.
2. Settings → Pages → Build and deployment → Source: **Deploy from a branch**.
3. Branch: `main` (или `docs`/`gh-pages`), folder: `/ (root)`.
4. Сайт будет доступен по адресу `https://<user>.github.io/<repo>/`.

Все пути в проекте относительные, серверные технологии не используются.

В настройках TMDB API добавьте домен GitHub Pages в список разрешённых (если включена проверка referrer).

## Как пользоваться

1. Введите название фильма или сериала в поиск.
2. Выберите результат — он попадёт в список.
3. Добавьте минимум **2** фильма.
4. Нажмите **Крутить барабан**.
5. После остановки барабан подсветит победителя и покажет название.

Дополнительно:

- **Перемешать** — меняет порядок чипов.
- **Очистить список** — удаляет все фильмы.
- **✎** на чипе — редактирует название.
- **⚙️** — скорость вращения, звук, полный сброс.

## Структура файлов

```
index.html      — разметка
style.css       — стили и тема
config.js       — API-ключ и константы
script.js       — логика (классы MovieSearch, MovieList, SlotMachine, SoundManager, App)
manifest.json   — PWA-манифест
sw.js           — кэш оболочки и постеров
assets/         — иконки и заглушка постера
```

## Технические детали

- Чистый JavaScript (ES6+), без фреймворков и сборки
- CSS Custom Properties для темы
- Google Fonts: Montserrat + Playfair Display
- Постеры: lazy loading в списке/поиске, предзагрузка перед спином
- Кэш постеров TMDB через service worker и обычный HTTP-кэш браузера
- Минимальная длина запроса — 2 символа; параллельный поиск `ru-RU` и `en-US`, объединение по id

## Браузеры

Современные Chrome, Firefox, Safari, Edge. Для PWA нужен HTTPS (GitHub Pages его даёт).
